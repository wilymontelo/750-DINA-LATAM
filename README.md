# +750 Dinámicas de Natación

Landing page estática en español neutro, preparada para GitHub y Vercel.

## Publicar en Vercel

1. Crea un repositorio nuevo en GitHub.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En Vercel, selecciona **Add New > Project** e importa el repositorio.
4. Mantén **Framework Preset: Other** y deja vacíos los comandos de build.
5. Publica el proyecto.

## Configuración incluida

- Checkout de Hotmart configurado en los botones de compra.
- Pixel de Lowtrack instalado en el `<head>`.
- Contador real hasta la medianoche local del visitante.
- Imágenes y páginas premium optimizadas en WebP.
- Página estática sin dependencias ni proceso de compilación.
